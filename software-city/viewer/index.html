      How to read the city

      Packages are districts; top-level Java types are buildings.

      Height represents declared methods. Footprint uses the field count, with a minimum area and a cap for large types.

      Height = 1 + 2 × log₂(1 + methods). Area weight = 1 + min(63, fields). Gutters keep buildings apart.

      Changing the color metric does not change a building's dimensions. Exact counts are shown above. Source lines describe a declaration's inclusive span, not logical lines of code.

      Drag to orbit · Right-drag to pan · Scroll or pinch to zoom

      Search dims other buildings. Use ↓ from search, then arrow keys and Enter to select.
