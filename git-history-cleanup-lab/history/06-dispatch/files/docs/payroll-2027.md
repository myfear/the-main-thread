# Payroll export, January 2027 (PAY-501)

This is an approved requirement for the January 2027 rollout in this fictional lab.
It is not the policy for the November 2026 payroll run.

The replacement export accepts individual minutes. For standard contracts, payroll
will pay every minute worked above the weekly allowance. Flat-rate contracts still
receive no separate overtime payment (INC-412).

The rollout replaces the 15-minute block rule introduced for the CSV import in
PAY-88. The current payroll service still requires those blocks until the rollout.
Format support and the decision to pay exact minutes are both part of PAY-501.
