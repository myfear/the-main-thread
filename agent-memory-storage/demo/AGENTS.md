# Agent Memory Lab

This workspace is a bounded file-backed memory exercise.

- Memory records live under `memory/users/<user-id>/`
- Mutations go through `python3 -m app.memory`
- Do not edit `memory/` with native file tools
- `.bob/` and `AGENTS.md` are control files; do not change them during memory tasks
- User id for this lab: `demo-user`
- Run `python3 -m unittest discover -s tests -v` after code changes
