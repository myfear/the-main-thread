# January 2026 Docling/RAG example (historical)

This directory contains the companion for the [January 2026 Docling/RAG tutorial](https://www.the-main-thread.com/p/enterprise-rag-quarkus-docling-pgvector-tutorial). Its implementation is retained as historical context.

For a new project, start with the [maintained April guide](https://www.the-main-thread.com/p/enterprise-rag-quarkus-docling) and the [current enterprise-rag companion](../enterprise-rag/README.md). That companion contains the current Java, Quarkus and Docling setup, source inspection endpoints, and reader verification commands.
