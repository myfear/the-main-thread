# Quarkus Gradle Build Lab

This demo supports The Main Thread tutorial for Maven users learning Gradle with Quarkus. The application exposes build metadata generated by a custom Gradle task, which makes the task graph, declared inputs and outputs, and up-to-date checks visible in a small Java service.

## Requirements

- JDK 25
- Network access for the first Gradle wrapper run

## Run in Dev Mode

```bash
./gradlew quarkusDev
```

Then read the generated metadata:

```bash
curl http://localhost:8080/build-info
```

Expected response:

```json
{"name":"quarkus-gradle-build-lab","version":"1.0.0-SNAPSHOT"}
```

## Verify the Build

```bash
./gradlew test
./gradlew generateBuildInfo
./gradlew generateBuildInfo
```

The second `generateBuildInfo` run reports `UP-TO-DATE`. Change the project input with `-Prevision=1.0.0` to make Gradle execute the task again:

```bash
./gradlew generateBuildInfo -Prevision=1.0.0
```

## Package the Application

```bash
./gradlew quarkusBuild
java -jar build/quarkus-app/quarkus-run.jar
```
